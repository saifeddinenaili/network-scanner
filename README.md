# Network Scanner

A Python-based network scanner for discovering active hosts,
resolving hostnames, scanning TCP ports, and generating CSV reports.

## Features

- Detect active hosts
- Resolve hostnames
- Scan TCP ports
- Multithreaded scanning
- Generate CSV reports

## Technologies

- Python
- Socket
- IP Address
- Subprocess
- Concurrent Futures
- CSV

## Usage

Run:

```bash
python scanner.py
